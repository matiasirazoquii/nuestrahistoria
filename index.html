Permisos de Firebase

Para permitir sincronización en la nube entre dispositivos, publica esta regla en Firebase Console > Firestore Database > Reglas: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
¡Atención! Si usas traductor de navegador, no dejes que traduzca rules_version a versión con tilde 'ó', ya que Firebase dará error de sintaxis.

Mientras tanto, tus cambios se guardarán localmente en tu navegador.
